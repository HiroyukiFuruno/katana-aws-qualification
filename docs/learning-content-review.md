# 教材と図解のレビュー手順

KAQでは、学習者が実務の構成図や要件を読み、設計案を選び、その理由と運用時の確認方法を説明できることを目指す。学習目標を「誰が、どんな状況で、何を理由付きで判断できるか」の形で一文にする。

## 1. 原稿だけで意味が通るか

図を隠して日本語原稿を読む。対象、行為者、前提条件、判断結果とその理由が、必要な順番で分かるか確認する。数値が判断条件になる場合は、その場で母数と指標を示す。例えばリクエスト数とエラー件数が同じ表にある場合は、判断の説明でもどちらの件数を使うか明記する。独立した確認問題は、単元名や前のスライドを見なくても、誰が何を判断するのか分かる形にする。分からない箇所は本文や設問を先に直す。AWSの事実と日本語用語は、該当箇所をAWS公式資料の日本語版で確認する。

## 2. 図から理由を説明できるか

「この図を読み、学習者は何を見比べ、どんな結論を理由付きで出せるか」を書いてから作図する。一文や短い表で同じ判断をしやすい場合は、その形式を使う。

| 学びたい判断 | 図で見せるもの |
| --- | --- |
| 配置や境界を変えると、どこまで通信できるか | Draw.ioの構成図で、関係するリージョン、VPC、AZ、サブネットなどを囲い、各リソースを所属する区画に置く。通信は発信元、宛先、向きと凡例を示し、ルートテーブルやポリシーは経路を決める設定だと分かる位置に置く。 |
| 同じ測定結果でも評価期間を変えると結論が変わるか | 同じデータを比較グラフに置き、集計範囲・閾値・結論が変わる理由を読めるようにする。 |
| どの工程を自動化すると、どこで人の判断が残るか | 並べた手順図で共通の工程を揃え、人の判断が入る箇所を示す。 |

本文に、着目する境界や比較する箇所を一文で示す。日本語の教材では日本語の図と代替テキストを使い、他の9言語では共通の英語版を使う。読む手掛かりは本文の言語に合わせ、図と同じ呼び方で境界や値を説明する。構成図は編集可能な `.drawio` と、そのファイルから書き出した掲載用SVGを残す。新しいSVGのラベルはSVGの文字要素で書き出し、HTMLの埋め込みを避ける。実際の教材枠で、スマートフォンでもラベルの末尾まで読め、区画と矢印を区別できるか確認する。明色・暗色の画面と、図を単独で開いたときの両方で、背景とラベルに十分な明暗差があるか確認する。資格別学習の図を追加したときは、模擬試験の出題中と採点後の画面に現れないことも確認する。

本文が図のラベル、軸、区画、矢印に言及する場合は、両方の掲載用SVGを開いて本文の案内に従って辿れることを確認する。資格別学習の日本語で案内文を「図」から書き始め、図からそのまま引用するラベルは「」で囲む。ビルドで掲載用SVGのラベルと照合する。日本語版と英語版でサービスの境界、矢印の向き、数値、判断条件を揃える。各図の取得先、原本、代替テキスト、掲載位置と拡大設定は `src/images/catalog.json` に登録する。ビルドは、教材図の言語、公開ファイル、図の参照位置、模試への混入を検査する。

## 3. 条件を一つ変えて、同じ考え方を使えるか

条件を一つ変え、図のどの関係を使えば判断できるか説明できる設問を使う。設計を扱う教材では、複数の案が成り立つ場面で、公開範囲・可用性・費用・運用負荷のうち関係する条件を示し、採用案を理由と検証方法まで説明できるようにする。設問や解説だけを読んでも、判断する条件と正答の理由が分かることを確認する。「図の各段階」など、図を指す表現がある場合は、その単元に掲載する図と照合する。設問の条件を直した場合は、全選択肢、正答キー、採点、解説を再判定する。選択肢を掲載順に見直し、正答が毎回同じ位置に集まっていないことも確認する。

### 記入例　公開ALBと非公開EC2

- **学習目標**　EC2を公開せずにWebサービスを提供できる理由と、片方のAZでだけS3に接続できない場合の調べ方を説明できる。
- **原稿の判定**　ブラウザーはALBに接続し、ALBは非公開EC2へ別の接続を開く。各プライベートサブネットに同じS3ゲートウェイエンドポイントを指す経路がある。図を隠しても説明できる。
- **図の判定**　公開・非公開サブネット内にALBとEC2を置き、S3をVPCの外に置く。ブラウザーとALB、ALBとEC2、EC2とS3の各接続を見分けられる。サービス名を矢印でつないだだけの図では、EC2がどこにあり、二つのサブネットでどの設定をそれぞれ確認するかを判断できない。
- **応用の判定**　AZ BだけS3への接続がタイムアウトし、両AZで同じIAMロールとセキュリティグループを使っている。AZ Bのプライベートサブネットに関連付くルートテーブルとS3への経路をAZ Aと比べる理由を説明できる。

作業台帳またはPRには、対象の教材、学習目標、原稿のみで確認した事実、採用した表現と図で読み取れる判断、条件を変えた設問と正答の理由、検証結果を記録する。
