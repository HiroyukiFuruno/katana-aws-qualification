# KAQ LPの構成・訴求・視覚階層

## ユーザー指示と根拠

2026-11-20の指摘と7418.pngに基づく。従来のコンセプトは平文の追記にとどまり、訴求・見た目の役割がなかった。学習・査定への到達を優先しすぎていた。コンサル資料のように、強調語の色・サイズ・一文字などで主張を伝え、理解してから行動へつなぐ。

## 情報の順序

1. Hero: 「気楽に学ぶ、AWS。」。強調語を青く大きく見せ、単字「学」を視覚的なアンカーにする。最初の導線はコンセプトを読むためのページ内リンク。
2. Concept: 2段組みの構造と強調語で、短い学びを日常へ取り入れる考え方を説明。用途説明は罫線で分け、試験対策はその一つに置く。
3. Value: 「1問から」「答えの理由」「登録に縛られない学び」を、実装済みの問題・解説・ゲスト利用と結びつける。教材数はここで補足する。
4. Next step: 価値を理解した後に学習・査定を選べるようにする。
5. Account: 準備中機能を含む登録情報は補足の開閉欄に置き、主たる訴求や最初の行動にしない。
6. FAQ: 読後の不安を解消する。

## 見た目のルール

白・ネイビー・青系の既存色を利用。Heroの文字は本文の2倍以上のサイズ、主張の語は色を分ける。コンセプトは面と太い上罫線、提供価値は番号と細い罫線で整理。カードを浮かせる影や過剰な丸み、意味のない大きな空白は避ける。本文は16px以上、読み幅と行間を保つ。スマホでは段組みを一列にし、装飾の単字は非表示にする。ダーク表示も既存の色トークンに追従する。
