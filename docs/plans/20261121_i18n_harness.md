# #75 多言語UIの漏れ防止

Issue: https://github.com/HiroyukiFuruno/katana-aws-qualification/issues/75

## 指摘と対応範囲

- [ ] ユーザー指摘: 多言語化漏れが繰り返されるため、画面文言のハードコーディングを禁止する静的解析を追加する。
- [ ] JSX本文、表示属性、式に埋め込まれた文言、追跡可能な定数を構文木で検査する。日本語だけでなく英語の直書きも検出する。
- [ ] `src`を再帰的に探索し、翻訳キーの参照を検査する。コメントや文字列中のコード例を参照と誤認しない。
- [ ] 見つかったUI文言を10言語の辞書へ移し、見出し・説明・操作・アクセシビリティ名を同じ言語に揃える。

翻訳対象のUI文言は`messages`と`usePreferences().t`を使う。表示属性だけを別言語で直書きする、ネストしたディレクトリを検査しない、既存違反をbaselineやファイル除外へ移す、任意の`translate="no"`で検査を逃がす運用は禁止する。

ブランドの固有名は訳語を創作せず、辞書内で共通名を管理する。言語選択肢は各言語の辞書に置いた自称を使う。URL・CSS・API列挙値・非表示の診断文字列などを表示文章と混同しない。

本件はUIの検査であり、外部データや教材本文を静的検査だけで翻訳済みと保証しない。教材の翻訳範囲は既存の公開契約を維持し、検査の検出範囲と限界を文書化する。
