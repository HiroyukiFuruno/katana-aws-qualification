# LPの登録訴求・SEO・画像の統一

2026-11-20の追加指示: アカウント作成の訴求が弱い、AWS認定資格のSEO語句が消えた、「学」がロケール変更で違うフォントになる。

- 主題の「気楽に学ぶ」を維持し、導入文・用途のH3・検索title/descriptionに「AWS認定資格」を明示する。H1へ試験対策を戻さない。
- 提供価値の直後、学習・査定の前に登録専用セクションを設ける。無料・外部アカウントによるログイン・連携/削除の自己管理を現在提供済みの内容として説明し、大きな作成ボタンを置く。スマホの読み順も見出し→メリット→ボタンとする。
- 履歴のアカウント同期・分析は準備中であることをセクション末尾に明示する。現在提供済みと誤認させない。後段の開閉欄は「アカウントとデータ」とし、補足情報の役割を分ける。
- 「学」はユーザーの追加指定により旧字体「學」へ変更し、文字・font-familyの描画を廃止し、Hiragino Mincho ProN W6の字形を輪郭化したSVG画像として固定する。SVGはpathのみでフォントを参照しない。共通画像をCSS maskで使い、テーマに応じて色だけ変える。フォントファイルや生成ツールは配布・build依存へ含めない。
- 全10ロケールで同じ画像URLと形を使用すること、SVGにtextがないこと、登録セクションと作成リンクの位置/表示、SEO語句の存在、80条件の幅/overflowを検査する。実Auth・レビュー・CI・完全なマージ済みsourceの照合・公開検査まで実施する。

## 共通の文字サイズとヘッダーの是正

- 見出しは共通トークンでH1 28〜36px、H2 22〜26px、H3 18〜20pxとし、LPでも拡大しない。強調は色・太さ・読み順で作る。
- ヘッダーは二段構成。一段目はブランド、言語、テーマ、アカウント。二段目の主要メニューは等幅4列で、一段目の名前の長さに依存させない。
- 言語・テーマは常時見えるが控えめな補助操作とする。名前欄は幅を予約し、省略表示と全文を表示するメニューを併用する。600px以下ではアイコンのみとし、ブランドもKAQ表記へ縮める。
- Flex/Gridの子はmin-width:0とし、可変長の表示名は一文字・通常・長い連結文字列を実Authで更新して検証する。ブランド・ナビ・補助操作・アカウントボタンの位置と幅が動かず、メニューの全文が画面内で折り返すことを検査する。
- 320/390/768/1280px、日英独で二段配置・等幅メニュー・操作表示・横はみ出しを検査する。LP・プライバシー・資格ページの見出し上限を検査する。CSS変更もAuth integrationの対象とし、実表示の回帰検査を必須にする。
